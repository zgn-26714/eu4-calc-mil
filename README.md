# EU4 陆战计算器 — 兵员伤害 / 士气 / 排名模拟

纯前端静态页面，浏览器直接打开 `index.html` 即可使用，无需后端或构建工具。

## 概述

这是一个仿照欧陆风云 4（Europa Universalis IV）陆战机制的战斗模拟器，提供三个逐步深入的计算模式：

1. **单日伤害计算** — 给定一个战斗阶段（火力/冲击），计算一天内双方兵员和士气损失
2. **多回合推演** — 连续模拟多个战斗回合，输出每日日志与胜负判定
3. **兵种排名** — 在当前科技等级下进行循环赛，对所有可用兵种排序；支持遍历科技排行、兵种成长折线图、多线高亮对比等

> 完整功能介绍请参阅 [FEATURES.md](FEATURES.md)

## 伤害公式

当前计算依据为本机 EU4 1.37.5 程序的反汇编、游戏配置和用户实测。基础伤亡用同尺度公式表示为：

```
P = 骰子 + 将领差 + 攻方进攻点数 - 守方防御点数 - 地形惩罚
等效基础伤亡 = min(110, max(5, 15 + 5P))
游戏内部基础值 = 25 + 25 × clamp(P + 2, 0, 21)
```

实际计算使用内部基础值，按固定顺序应用兵力、训练度、战术、科技等倍率，每一步乘除后截断至千分位。兵损换算系数0.2在对应伤害倍率之后、天数倍率之前应用，不能提前合并。战斗日从1开始，倍率为 `1 + 战斗日数 × 1%`。

士气交战伤害先计算造成伤害方最大士气÷2.7，再应用独立士气点数及各项倍率，每步截断；另加每团每日“敌方平均最大士气×1%”的被动损耗。职业度的火力/冲击加成影响兵损，不直接加进士气伤害。

多回合结果总览、每轮结果和每日日志同时列出“游戏显示”与“内部实际”士气。单团游戏显示经过两次兵力加权汇总，再截断至两位小数；内部实际保留三位小数，用于后续扣减及胜负判定。

验证：27天兵损在两种模拟模式下共108项检查全部吻合；初始士气2.56/2.57的新记录54个显示值全部吻合。旧3.35/3.39记录使用候选隐藏初值后匹配53/54，仍有一项差异。

> 完整公式推导与机制细节请参阅 [陆战机制.md](陆战机制.md)

### 模块设计

采用 **IIFE 模块模式**，所有模块挂载到全局 `window._M` 命名空间：

```javascript
(function(M) {
  // module code
  M['module/name'] = { exportedFunctions };
})(window._M = window._M || {});
```

数据层 → 共享计算引擎 → 各功能模块 → main.js 编排与事件绑定。

### 界面验收

有 Node.js、Playwright 与 Chrome 的开发环境可运行 `node tests/ui-regression.cjs`。Windows 默认使用已安装的 Chrome；其他环境使用 Playwright Chromium，也可通过 `CHROME_PATH` 指定浏览器。`PLAYWRIGHT_MODULE` 可指定 Playwright 模块路径，`EU4_SCREENSHOTS` 可指定截图目录。

验收涵盖三种模式与当前 Git HEAD 参数读取的数值对比、每日趋势与日志一致性、回放控制与不重算保证、输入保留、四种屏宽、科技排行、筛选、弹窗键盘焦点、两类排行导出和减少动画。具体范围见 [界面验收记录](docs/ui-acceptance.md)。

## 数据来源

- 兵种表来自 EU4 游戏内数据，包含 **约 380 个兵种**，覆盖所有兵种组（Western、Eastern、Ottoman、Indian、Chinese、Muslim 等）
- 科技修正覆盖 **科技等级 0-32**
- 每个兵种包含：火力攻/防、冲击攻/防、士气攻/防点数

## 已知局限

1. 模型假设每个团 1000 人，固定在前排作战
2. 引擎保留后排炮兵系数选项，但没有完整还原后排部署及士气传递机制
3. 未处理炮兵在前排受双倍伤害的机制
4. siege 将领点数当前锁定为 0，无实际效果
5. 未模拟侧翼攻击、增援等高级战场机制
6. 多团缺乏逐团状态，暂仅提供模型内部总士气，不能还原游戏提示框的多团汇总

## 使用方法

直接双击 `index.html` 用浏览器打开即可，无需任何服务器或构建步骤。推荐使用 Chrome / Firefox / Edge 最新版本。

### 操作流程

1. 在左右两侧分别填写进攻方和防守方的配置
2. 选择计算模式（单日 / 推演 / 排名）
3. 点击对应的计算按钮
4. 查看结果
