# EU4 陆战计算器 — 兵员伤害 / 士气 / 排名模拟

纯前端静态页面，浏览器直接打开 `index.html` 即可使用，无需后端或构建工具。

## 概述

这是一个仿照欧陆风云 4（Europa Universalis IV）陆战机制的战斗模拟器，提供三个逐步深入的计算模式：

1. **单日伤害计算** — 给定一个战斗阶段（火力/冲击），计算一天内双方兵员和士气损失
2. **多回合推演** — 连续模拟多个战斗回合，输出每日日志与胜负判定
3. **兵种排名** — 在当前科技等级下进行循环赛，对所有可用兵种排序；支持跨科技对比

## 功能特性

### 双方配置

- 左右双栏分别填写进攻方和防守方
- 攻守双方可独立选择**兵种组**（Western / Eastern / Ottoman / 等 14 个兵种组）
- 根据兵种组、兵种类型（步兵/骑兵/炮兵）、**军事科技等级**自动匹配对应兵种
- 完整编辑双方将领属性：火力、冲击、机动、 siege（siege 当前锁定为 0）
- 独立调节火力/冲击阶段骰子（随机 / 固定值 / 手动输入序列）
- 支持所有 EU4 修正项输入：
  - 训练度、作战能力、兵力（100-1000）
  - 火力/冲击伤害修正、伤害 inflicted / received
  - 士气加成、陆军传统、威望
  - 士气伤害增减修正
  - 职业度（影响被动士气丢失）
- **河流渡河惩罚**与将领机动抵消机制

### 三种计算模式

#### 1️⃣ 单日伤害计算（Single Day）

- 选择阶段（火力/冲击）计算单日伤害
- 详细列出基础伤亡、最终伤亡、伤亡倍数
- 同时显示兵员损失和士气损失

#### 2️⃣ 多回合推演（Simulation）

- 持续模拟多个战斗回合，每回合包含火力（3 天）+ 冲击（3 天）
- 每日记录：骰子点数、攻防将领差值、当日伤亡、剩余兵力、当前士气
- 士气崩溃 / 全歼时自动停战
- 输出胜负判定、双方剩余伤亡统计

#### 3️⃣ 兵种排名（Ranking）

- 在当前配置下，列出所有可用兵种进行**循环赛**
- 每对兵种战斗两次（轮流进攻），士气崩溃或满 200 回合结束
- 评分规则：胜 3 分 / 平 1 分 / 负 0 分
- 排名依据：积分 > 胜场 > 净士气 > 净兵力
- 支持导出 CSV
- **跨科技排名**：遍历科技等级 0-32，输出各兵种组在不同时代的实力曲线
- 跨科技 SVG 折线图可点击放大

### 特殊细节

- **独立骰子**：火力阶段和冲击阶段各自独立掷骰，进攻方和防守方也可独立设置
- **将领抵消河流惩罚**：若进攻方机动 > 防守方机动，则忽略河流渡河惩罚
- **炮兵科技锁**：科技等级 < 7 时自动禁用炮兵选择
- **职业度对被动士气加成**：职业度 >= 100 时被动士气丢失减半
- **兵力上限提醒**：超过 1000 时提示部队已超模

## 伤害公式

伤害计算分两步：基础伤亡 → 乘数放大。

### 第一步：基础伤亡

```
基础伤亡 = max(15, 15 + 5 × (骰子 + 将领差 + 攻方进攻点数 - 守方防御点数 - 地形惩罚))
```

五个因子，每个被 ×5 放大。骰子 0-9 的差距可达 45 基础伤亡差，是战斗最大变量。

| 因子 | 说明 |
|------|------|
| 骰子 | 0-9，每阶段双方各掷一次 |
| 将领差 | max(0, 己方将领点数 − 对方将领点数)，按阶段取火力/冲击 |
| 攻方进攻点数 | 进攻方兵种进攻点数（火力Off/冲击Off） |
| 守方防御点数 | 防守方兵种防御点数（火力Def/冲击Def） |
| 地形惩罚 | 仅攻方承受，地形(-1~-2) + 渡河(-1)；攻方机动 > 守方机动时可抵消渡河惩罚 |

### 第二步：乘数放大

```
乘数 = (兵力/1000)
     × (科技修正 / 守方战术)
     × (1 + 作战能力/100)
     × (1 + 训练度/100)
     × (1 + 造成伤害修正/100)
     × (1 + 守方承受伤害修正/100)
```

**科技修正** = 基础科技修正 + 阶段伤害修正。阶段伤害修正直接与基础科技修正相加，不是独立乘数。

**守方战术** = (基础战术 + 额外战术) × (1 + 守方训练度/100)。

包含兵种/阶段特异性取值：
- **作战能力** 按步兵/骑兵/炮兵分别取对应值
- **造成伤害/承受伤害** 按火力/冲击阶段分别取对应值（如 `damageDoneFire`），无阶段特定值则回退到通用值

### 最终兵力伤害

```
最终伤害 = 基础伤亡 × 乘数
```

### 士气伤害

```
最大士气 = baseMorale(科技等级) × (1 + 士气加成/100 + 传统×0.0025 + 威望×0.001 + ...)

士气伤害 = 最终伤害 × (1 + 士气伤害输出/100) × (1 + 士气伤害承受/100) × (己方最大士气 / 540)
```

被动士气丢失：`0.01 × 敌方平均士气`，职业度 ≥ 100 时减半。

### 训练度的双重作用

训练度同时出现在分子（乘数中的 ×(1+训练度/100)）和分母（放大守方战术），是唯一攻防双加属性。

### 模块设计

采用 **IIFE 模块模式**，所有模块挂载到全局 `window._M` 命名空间：

```javascript
(function(M) {
  // module code
  M['module/name'] = { exportedFunctions };
})(window._M = window._M || {});
```

数据层 → 共享计算引擎 → 各功能模块 → main.js 编排与事件绑定。

## 数据来源

- 兵种表来自 EU4 游戏内数据，包含 **约 380 个兵种**，覆盖所有兵种组（Western、Eastern、Ottoman、Indian、Chinese、Muslim 等）
- 科技修正覆盖 **科技等级 0-32**
- 每个兵种包含：火力攻/防、冲击攻/防、士气攻/防点数

## 已知局限

1. 模型假设每个团 1000 人，固定在前排作战
2. 未处理炮兵在后排伤害减半的机制
3. 未处理炮兵在前排受双倍伤害的机制
4. siege 将领点数当前锁定为 0，无实际效果
5. 未模拟侧翼攻击、增援等高级战场机制

## 使用方法

直接双击 `index.html` 用浏览器打开即可，无需任何服务器或构建步骤。推荐使用 Chrome / Firefox / Edge 最新版本。

### 操作流程

1. 在左右两侧分别填写进攻方和防守方的配置
2. 选择计算模式（单日 / 推演 / 排名）
3. 点击对应的计算按钮
4. 查看结果
