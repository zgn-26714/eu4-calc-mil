## 自动验收

`tests/ui-regression.cjs` 使用真实浏览器运行静态入口，覆盖：

- 单日、多轮与排行的完整计算结果对比；断言计算引擎、计算编排、兵种及科技数据文件没有更改。
- 全部表单控件、已修改项数、键盘折叠、模式切换、计算后返回。
- 固定骰子、手动序列、随机骰子、单轮、20 轮上限、提前溃败、多团场景中的每一天；校验兵力、两种士气表示、条形比例、日志与曲线点数。
- 播放与暂停、四种速度、首尾定位、播放结束、重播、重算重置；随机模式回放时随机调用数保持不变。
- 所有具备至少两种候选兵种的科技等级、四张科技成长图、图例高亮、具体兵种名称、兵种显示切换、筛选清除后重新筛选、窄屏筛选菜单与模板浮层。
- 弹窗 Tab 焦点循环、Escape 关闭和焦点恢复；日志 TXT 与科技排行 CSV 下载；减少动画偏好。

UI 测试采用固定随机序列，以便结果可重复；这不改变实际页面的随机骰子行为。

## 保留的计算口径

胜负、士气、兵员损失与科技数据均沿用现有模型。单团「游戏显示」仍经过原有加权汇总与截断，「内部实际」继续用于状态比例和递推。多团游戏显示仍标注暂不支持。没有加入国家配置或国家旗帜。
